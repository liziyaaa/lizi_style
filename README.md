# 比肩 · Side by Side

一个完全在浏览器中运行的情侣身高、体型与穿搭比例对比工具，适合 GitHub Pages。

## 功能

- 男女分别设置身高（130–210 cm）、体重（35–160 kg）。
- 原创亚洲青年风格二维参数化人物；正面、侧面、剪影。
- 自然匀称、柔和轮廓、运动轮廓、腰胯明显四种身形。
- 日常简约、贴身基础、休闲运动、通勤约会四种穿搭，以及四种配色。
- 鞋底增高单独设置（0–10 cm），区分裸足身高差与视觉身高差。
- 调整站位距离、交换左右、显示或隐藏身高尺。
- 收藏最多 12 组方案，保存在当前浏览器 localStorage。
- 导出 1760 × 1524 PNG 对比图。
- 手机和电脑布局，无外部字体、CDN 或第三方运行依赖。

## 直接体验

下载并打开 `bijian.html`。这是单文件离线版，不需要安装软件或启动服务器；浏览器的本地文件存储策略可能影响收藏能否跨次保留。正式使用建议部署到 GitHub Pages。

## GitHub Pages 部署

1. 当前项目仓库为 `liziyaaa/lizi_style`，代码已提交到 `main` 分支。
2. 页面入口为仓库根目录的 `index.html`，无需安装依赖或构建。
3. 在仓库 **Settings → Pages → Build and deployment** 中，将 Source 设为 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)`，保存。若默认分支不是 `main`，选择实际分支。
5. 等待 GitHub 部署完成，使用 Pages 设置中显示的网址。所有资源都采用相对路径，适合仓库子路径。

不必配置 Actions 工作流、不需要密钥、付费 API 或后端。

GitHub 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 模型的含义与限制

人物为原创矢量示意，并非真人照片、三维扫描或中国人体测量数据库。

纵向坐标以 180 cm 参考人体建立，再统一按输入身高缩放；两人使用同一厘米刻度和地面。鞋底高度另加。头身比固定，头顶与身体部位的相对位置只是估计。

体型通过体重与身高的比例，连续改变躯干、四肢的宽度；身形选项再调整肩、腰、胯等位置。该映射是用于视觉示意的自定义模型，未经真实人群数据标定；相同身高体重的人可能有很不一样的外形，极端输入误差更大。身形切换不保证体积或真实体脂率守恒。

输入不会发送给服务器，也不会写进 GitHub 仓库。收藏仅保存在当前浏览器；清理网站数据会移除收藏，其他设备不会自动同步。图片会包含当前身高体重，分享前可自行检查。

工具不评判吸引力或情侣是否合适；它只帮助观察站在一起的比例。

## 文件

- `index.html`：页面结构。
- `style.css`：布局与视觉样式。
- `app.js`：模型绘制、参数调整、收藏及 PNG 导出。
- `bijian.html`：上述三个文件合并的单文件版本。
- `.nojekyll`：按静态文件发布。
- `CHECKS.md`：当前版本验证记录。
